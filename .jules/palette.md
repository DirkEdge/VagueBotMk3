## 2026-06-09 - Actionable Discord Bot Error Responses
**Learning:** For a Discord bot text-based interface, generic error messages leave users stranded when agent logic loops fail.
**Action:** When creating text interfaces for LLM agents, always append actionable troubleshooting tips (e.g., "try `!clear` to reset the chat state") to system error messages so users can self-serve workarounds.
