## 2026-06-17 - Actionable Error Recovery
**Learning:** In headless/text-based interfaces like Discord, raw error messages often leave users stranded because there are no visual reset buttons. Providing explicit recovery commands (e.g., `!clear`) within the error message itself significantly reduces user friction and hidden context bounds.
**Action:** Always append context-aware recovery suggestions (like state reset commands) to surface-level error handlers in conversational bots.
