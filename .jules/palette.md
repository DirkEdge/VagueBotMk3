## 2024-05-18 - Actionable Error Messages for Context Bounds
**Learning:** Users in Discord bot interfaces often encounter opaque context bounds errors and feel stuck. Actionable error messages that suggest explicit reset commands (like `!clear`) are critical for recovery.
**Action:** Always provide explicit, actionable recovery steps (e.g., suggesting specific commands or strategies like breaking down prompts) when exposing system errors to users in text-based interfaces.
