## 2024-05-31 - [Discord tool kwargs parsing formatting]
**Learning:** Found that when `_async_ask_user_with_buttons` attempts to ask for confirmation from the user to execute a specific tool with its parameters (`kwargs`), it falls back to formatting parameters using a raw `str(kwargs)`. This looks clunky and isn't pleasant or readable. Also, there's a memory indicating: 'For Discord bot tool parameter outputs, format dictionaries using `json.dumps(kwargs, indent=2, ensure_ascii=False)` enclosed in Markdown JSON blocks for better readability. Include a fallback to `str()` if JSON serialization fails.'
**Action:** Always wrap kwargs parameters when formatted using JSON in ````json ... ```` formatting to ensure clear syntax highlighting and better readability for users reviewing Discord interactive messages. Also make sure to properly close markdown blocks if truncated.
