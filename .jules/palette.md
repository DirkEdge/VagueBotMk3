## 2026-06-11 - Add latency feedback to ping command
**Learning:** In text-based interfaces like Discord bots, simple text responses to status checks (like "pong") can feel disconnected. Including latency information makes the feedback much more transparent, reassuring users of bot responsiveness and connection health.
**Action:** When implementing status or heartbeat commands in chat interfaces, always include performance metrics (like latency or uptime) alongside simple string responses to improve user trust and UX transparency.
