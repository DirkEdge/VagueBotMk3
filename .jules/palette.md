## 2024-07-01 - Actionable Error Messages and Interaction Feedback
**Learning:** Users can become frustrated when facing generic errors or lack of interaction feedback in text-based Discord bots, especially when hidden context limits block their progress.
**Action:** Always provide actionable recovery suggestions (like explicitly suggesting state reset commands such as `!clear`) in error messages, and add meaningful feedback (like latency metrics) to basic commands to improve the perceived responsiveness of the bot.
