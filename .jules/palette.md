## 2024-05-18 - Actionable Error Messages in Headless Environments
**Learning:** In headless text UI environments like Discord bots, standard error messages often lack the context or affordances available in graphical UIs. When users encounter errors related to hidden state constraints (like context limits), they often get stuck.
**Action:** Always provide actionable suggestions (e.g., specific commands to run like `!clear`) alongside error messages to empower users to resolve the issue themselves.
