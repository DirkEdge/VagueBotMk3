## 2024-07-03 - Discord Bot Interaction Feedback and Error Recovery
**Learning:** Text-only interfaces like Discord bots require explicit system health metrics (like latency on ping commands) and actionable recovery paths in error messages to help users overcome hidden constraints (like context bounds or agent loops).
**Action:** Always include measurable interaction feedback on health-check commands and append actionable recovery suggestions (e.g., state reset commands) to generic error catch-alls.
