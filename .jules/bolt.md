## 2026-06-03 - Async Atomic File I/O Optimization
**Learning:** Saving state (like JSON chat histories) synchronously in the main thread blocks the async event loop, reducing throughput. Offloading state persistence to a single-worker `ThreadPoolExecutor` ensures thread safety, background execution, and sequential write ordering, while using `.tmp` file replacement ensures data integrity. Passing stringified JSON (`json.dumps()`) to the background thread is significantly faster than using `copy.deepcopy()` to solve the `RuntimeError: dictionary changed size during iteration` issue.
**Action:** When implementing frequent state persistence in an async context, serialize state to a string in the main thread, and pass that string to a background thread pool (with max_workers=1) to perform the file write atomically via `.tmp` file replacement.
