## 2024-07-04 - Offloading Blocking I/O to Prevent Discord Event Loop Latency
**Learning:** In a Python Discord bot (`asyncio`) environment, performing synchronous disk I/O (like file writes) on the main event loop thread causes the loop to block, increasing latency and risking timeout disconnections. Offloading this to a background thread improves overall responsiveness. Furthermore, serializing state to a string (`json.dumps()`) in the main thread before passing it to the executor avoids concurrent modification exceptions (`RuntimeError: dictionary changed size during iteration`) and is faster than deepcopy.
**Action:** Always offload synchronous file I/O using a `concurrent.futures.ThreadPoolExecutor` when modifying state asynchronously. Use atomic writes (`os.replace`) to prevent data corruption during saves.
