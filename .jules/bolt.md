## 2026-06-14 - Thread Safety in asyncio File Persistence
**Learning:** In a heavily asynchronous Python application (like this Discord bot), saving state directly inside the asyncio event loop using synchronous `json.dump` can cause the event loop to block, leading to perceived latency. Additionally, iterating over a dictionary being actively modified by other asynchronous tasks leads to `RuntimeError: dictionary changed size during iteration`.
**Action:** When persisting state, serialize the state dictionary to a string in the main thread (to avoid concurrent modification exceptions) and then offload the actual file I/O to a background thread using `concurrent.futures.ThreadPoolExecutor(max_workers=1)`. The single worker guarantees FIFO ordering to prevent race conditions during rapid successive saves.
