## 2026-06-07 - Non-Blocking Chat History Persistence
**Learning:** In a Discord bot receiving frequent messages, saving state synchronously via `json.dump` inside the main event loop blocks the entire process, causing high latency. Offloading to an async thread (e.g. `ThreadPoolExecutor`) requires thread-safe state management. Specifically, directly deep-copying `dict`s across threads while they are being actively mutated in the main thread leads to `RuntimeError: dictionary changed size during iteration`.
**Action:** Always serialize the volatile state to a JSON string in the main thread before passing it to the worker thread. Use a single-worker `ThreadPoolExecutor` to preserve FIFO ordering of writes, and ensure the write is atomic (write to a temporary `.tmp` file and `os.replace`) to prevent file corruption during sudden restarts or crashes.
