## 2024-06-25 - Safe Thread-Offloading of State Persistence
**Learning:** When offloading state serialization logic (like writing chat histories to disk) from a single-threaded async event loop to a background thread to prevent blocking, passing deep-copied dictionaries or relying on dictionary iterations in the background thread can trigger `RuntimeError: dictionary changed size during iteration` if the main thread modifies the state concurrently. Offloading raw `json.dump()` directly is thus unsafe.
**Action:** Always serialize the dictionary to a string using `json.dumps()` *within* the main thread first (which is fast), and then pass that serialized string to a single-worker `ThreadPoolExecutor` for the slower disk I/O operations (atomic writes). This ensures thread-safe data extraction while still preventing the main loop from waiting on I/O.
